## Important technical decision

Google AI Studio's native Android generation workflow may produce Kotlin and Jetpack Compose. The academic subject is Advanced Data Structures using Java. Therefore, use a **hybrid Android project** unless the faculty explicitly requires every layer to be Java:

- Android presentation layer: Kotlin + Jetpack Compose (generated by the Android workflow).
- Core route engine: pure Java classes, called from Kotlin.
- Persistence: Room/SQLite; Kotlin or Java repository layer.
- Google Maps Android SDK: native Android Maps SDK integration.
- Algorithms for the MCA demonstration: implemented in Java, documented and unit-tested.

If the faculty requires a Java-only application, replace the Compose UI with Java + XML and use the Google Maps SDK for Android Java APIs. Obtain faculty approval before final submission.

## Data accuracy policy

This project is an independent informational application and is not affiliated with Mumbai Metro operators or MMRDA. Do not assume that a line is operational merely because it appears in a master plan. Keep operational status, stations, interchanges, fares, timings and facilities in a source-traceable dataset. If a value cannot be verified, display “Not verified” or omit it.
